5. FEATURES BEING EVALUATED
═══════════════════════════════════════════════════════════════════════

System considers 8 factors:

    1. 💰 PRICE SCORE
       └─ How well product fits your budget
       └─ Best value when centered in budget range

    2. ⭐ RATING
       └─ Average customer rating (0-5 stars)
       └─ Higher = better quality

    3. 🎁 DISCOUNT
       └─ Discount percentage offered
       └─ But cheap ≠ good value

    4. 🏢 BRAND REPUTATION
       └─ How trusted is the brand
       └─ 0-10 score (Nike=9, No-name=5)

    5. 💬 CUSTOMER REVIEWS
       └─ Number of reviews received
       └─ More reviews = more validated quality

    6. 👥 POPULARITY
       └─ Rating × Number of reviews
       └─ Combination of quality and proof

    7. 💎 VALUE FOR MONEY
       └─ How much quality per rupee
       └─ Rating per unit price

    8. 📍 BUDGET FIT
       └─ How well centered in budget
       └─ Penalizes extremes


6. API ENDPOINTS EXPLAINED
═══════════════════════════════════════════════════════════════════════

Endpoint 1: POST /rank
    Purpose: Rank a list of products
    
    What you send:
        {
          "products": [
            {
              "productId": "1",
              "productName": "Nike Shoe",
              "price": 1200,
              "averageRating": 4.5,
              "discountPercentage": 15,
              "brandReputationScore": 8.5,
              "totalReviews": 450,
              "budgetMin": 1000,
              "budgetMax": 1500
            }
          ]
        }
    
    What you get:
        {
          "totalProducts": 1,
          "rankedProducts": [
            {
              "productId": "1",
              "productName": "Nike Shoe",
              "rankingScore": 0.78,
              "rank": 1
            }
          ]
        }

Endpoint 2: POST /explain
    Purpose: Explain why a product got its score
    
    Returns feature breakdown:
        "price_score": 0.8        (Good budget fit)
        "rating_normalized": 0.9  (Excellent rating)
        "discount_normalized": 0.6 (Good discount)
        "brand_score_normalized": 0.85
        ... (8 features total)

Endpoint 3: GET /health
    Purpose: Check if service is running
    
    Returns:
        {
          "status": "healthy",
          "model_loaded": true
        }

8. WHAT HAPPENS BEHIND THE SCENES
═══════════════════════════════════════════════════════════════════════

When you rank 50 products:

    Step 1: Feature Engineering (10ms)
    └─ Calculates 8 features for each product

    Step 2: Model Prediction (50ms)
    └─ XGBoost predicts ranking score for each

    Step 3: Sorting (1ms)
    └─ Sorts by score (highest first)

    Step 4: Response (50ms)
    └─ Returns ranked list to client

    Total Time: ~100-200ms per request
