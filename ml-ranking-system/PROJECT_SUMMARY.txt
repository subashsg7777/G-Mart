HOW IT WORKS (3 STEPS)
═══════════════════════════════════════════════════════════════════════════════

Step 1: Feature Engineering
  Input: Product data (price, rating, discount, brand, reviews, budget)
  Process: Calculate 8 normalized features (0-1 range)
  Output: Feature vector ready for model

Step 2: Model Prediction
  Input: Feature vectors from all products
  Process: XGBoost predicts ranking score for each
  Output: Scores 0-1 (higher = better product)

Step 3: Ranking & Response
  Input: Predicted scores
  Process: Sort by score (highest first)
  Output: Ranked products with explanations


8 ENGINEERED FEATURES
═══════════════════════════════════════════════════════════════════════════════

1. price_score        → How well product fits budget
2. rating_normalized  → Product rating (0-5 → 0-1)
3. discount_norm      → Discount percentage (0-100 → 0-1)
4. brand_score_norm   → Brand reputation (0-10 → 0-1)
5. reviews_norm       → Review count (popularity signal)
6. quality_pop        → Rating × Reviews (quality proof)
7. value_per_price    → Rating per unit cost
8. budget_fit         → Budget centering penalty


ML MODEL DETAILS
═══════════════════════════════════════════════════════════════════════════════

Algorithm:         XGBoost with rank:pairwise objective
Approach:          Learning-to-Rank (LTR)
Training Method:   Pairwise ranking (learns A > B preferences)
Labels:            1 = clicked/bought, 0 = ignored
Iterations:        100 boosting rounds
Max Depth:         5 (prevent overfitting)
Learning Rate:     0.1
Eval Metric:       NDCG (Normalized DCG)

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Solution: pip install -r requirements.txt

Problem: "Model file not found"
Solution: python train.py

Problem: API won't connect from Node.js
Solution: 
  • Check API is running
  • Verify port 8000 is accessible
  • Check RANKING_API_URL in .env

Problem: API takes >1000ms
Solution:
  • Use Gunicorn: gunicorn api:app -w 4
  • Cache predictions
  • Optimize features
